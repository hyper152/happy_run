# 步道乐跑使用教程

- **影梭：可用。** 用户反馈可用，基本操作见下文；不同设备和应用版本的兼容性可能不同。
- **Fake Location（FL）：可尝试。** 支持规划路线，作为备选放在本文后面；当前环境下能否使用需自行验证。

## 一、准备工作

- 一部支持 `arm64-v8a` 应用的 Android 手机。
- 已安装并可正常登录的步道乐跑。
- 影梭安装包：[Go_1.12.3_arm64-v8a_release.apk](./src/Go_1.12.3_arm64-v8a_release.apk)。

以下步骤均在真机上操作。

## 二、影梭（可用）

项目发布地址：[Gitee · 影梭 ReleaseV1.12.3](https://gitee.com/itexp/gogogo/releases/tag/ReleaseV1.12.3)。

### 安装

1. 将安装包传到手机，点击安装。
2. 打开影梭，按提示完成必要的权限授权。
3. 在系统设置中允许影梭 **显示悬浮窗／显示在其他应用上层**，用于显示控制面板。

## 三、设置模拟位置应用

1. 打开手机 **设置 → 关于手机 → 版本信息**。
2. 连续点击 **软件版本号／版本号**，直到提示已开启开发者模式。
3. 返回设置，进入 **开发者选项**。
4. 找到 **选择模拟位置信息应用**，选择 **影梭**。
5. 返回确认该项显示为“影梭”。

不同手机的设置路径可能不同，可在设置中搜索“开发者选项”或“模拟位置”。

## 四、启动影梭

1. 打开影梭，在地图中找到测试区域并选择起点。
2. 点击地图左下角的定位图标，启动位置模拟。
3. 如果出现悬浮窗授权提示，按提示开启权限后返回。
4. 确认屏幕上出现悬浮控制面板，再切换到步道乐跑。

## 五、乐跑操作

1. 打开步道乐跑，进入 **乐跑** 页面。
2. 点击 **开始乐跑**，按提示完成本人验证，等待定位和倒计时结束。
3. 进入记录页面后，通过影梭悬浮面板控制位置移动，观察定位和轨迹是否更新。
4. 完成定位测试后，在乐跑中暂停并结束记录，查看记录详情。
5. 返回影梭停止模拟；不再使用时，可在开发者选项中将模拟位置应用改回“无”。

## 六、常见问题

- **安装不兼容：** 确认手机系统支持 `arm64-v8a`，此安装包不适用于仅支持 32 位应用的系统。
- **悬浮面板不显示：** 检查影梭的悬浮窗权限，并返回影梭确认已启动。
- **位置不更新：** 检查系统定位开关、乐跑定位权限，以及模拟位置应用是否已选为影梭。
- **环境异常或闪退：** 保留完整报错，核对应用与系统版本；不同设备和版本的兼容性可能不同。

## 七、Fake Location（FL，可尝试）

安装包：[fl.apk](./src/fl.apk)。FL 支持 **路线规划／路线模拟**，可添加多个路线点，按规划的路线进行位置模拟；需要固定路线的定位测试时可以尝试。

1. 安装并打开 FL，按提示授予必要权限。
2. 在 **开发者选项 → 选择模拟位置信息应用** 中选择 **Fake Location**。
3. 打开 FL 菜单，进入 **路线模拟**，添加路线点并保存路线；具体按钮以所用版本界面为准。
4. 启动路线模拟，观察目标应用的位置是否更新；测试结束后停止模拟。

FL 在当前乐跑版本上的可用性尚未验证，因此标为“可尝试”。切换工具前先停止原工具，并重新选择模拟位置应用，不要同时运行两套模拟。

> 仅用于获得授权的定位测试与学习。模拟记录不代表真实运动，请遵守学校和平台规则；生成记录不等于计入校园考核成绩。
